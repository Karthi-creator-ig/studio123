# **App Name**: GlobalCue

## Core Features:

- Multi-Timezone Scheduler: Allows users to set meeting reminders by selecting the host country's time, automatically calculating local time offsets.
- Meeting Insight Tool: An AI tool that reasons through meeting titles and times to suggest a prepared context summary for each notification.
- Time-Conflict Optimization Tool: Uses AI reasoning to analyze participant timezones and identify the most respectful meeting windows across borders.
- Desktop Sound Engine: High-priority notification system with customizable alert tones specifically designed to cut through noise.
- Global Dashboard: A clean interface displaying all upcoming reminders with live countdowns in both local and international formats.
- Reminder Database: Persistent storage for all user settings, time preferences, and upcoming meeting alerts.
- Geo-Localized Clock Sync: Synchronizes app internal timers with global atomic time to ensure precision to the second for critical notifications.

## Style Guidelines:

- Primary color: Professional Iris Blue (#6C5CE7) to evoke a sense of trust, focus, and digital precision.
- Background: Deep Obsidian Navy (#1D1B26), providing a dark, high-contrast workspace that minimizes eye strain.
- Accent: Cerulean Sky (#54A0FF), a bright contrast for high-priority notification buttons and countdown alerts.
- Headline font: 'Space Grotesk' for a high-tech, geometric, and authoritative aesthetic.
- Body text font: 'Inter' to ensure absolute readability for dense data sets like meeting times and timezones.
- Minimalist line icons using sharp angles to match the 'Space Grotesk' typographic weight.
- F-pattern dashboard layout with persistent sidebars for timezone settings and a central scrollable list for reminders.
